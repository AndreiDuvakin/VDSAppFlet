# Selectel VDS Client Flet

## О проекте
Неофициальный Android-клиент для управления серверами [Selectel VDS](https://vds.selectel.ru). Приложение на библиотеке Flet, позволяющее работать с арендованными серверами прямо с телефона. Создан в учебных целях для изучения библиотеки Flet.

## Цель создания
Личный проект для практики разработки кроссплатформенного приложений на языке Python, а также для удобного доступа к своим серверам Selectel.
